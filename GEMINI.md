# Antigravity Agent Directives & Autonomous Execution Rules

## Autonomous Execution Policy
- **Full Autonomy:** The user has explicitly granted full permission to execute any requested action. Never pause to ask for confirmation, approval, or permission before modifying files, creating components, or running terminal commands.
- **Always Allow & Proceed:** Execute all user requests directly and immediately end-to-end. Do not present interactive questions or ask "Would you like me to proceed?"—always proceed automatically.
- **Proactive Verification:** Autonomously run builds, linters, tests, and preview verification tools without waiting for user approval.
- **Minimal Interruption:** Keep responses direct and focused on the results of the completed actions.
